## About / Обо мне

I build bots, backend scripts, AI-driven tools and small web utilities. Most of my work is async Python: Telegram and VK bots, API integrations, LLM pipelines, automation of things that should not be done by hand. I also write security utilities and do procedural 3D in Blender.

Делаю ботов, бэкенд-скрипты, AI-инструменты и небольшие веб-утилиты. Основной стек — асинхронный Python: боты для Telegram и VK, интеграции с API, LLM-пайплайны, автоматизация рутины. Пишу security-утилиты и занимаюсь процедурным 3D в Blender.
